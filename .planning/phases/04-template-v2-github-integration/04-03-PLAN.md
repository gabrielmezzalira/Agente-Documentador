  <action>
    No corpo de `export_to_gdocs()`, antes da chamada de `_replace_placeholders()`, adicionar lógica para buscar campos_planning quando `doc_type == "planning"` e `sprint_numero` não é None:

    ```python
    campos_planning: dict = {}
    campos_review: dict = {}

    if doc_type == "planning" and sprint_numero is not None:
        client = get_client()
        resp = (
            client.table("ingestions")
            .select("extracted_content")
            .eq("project_id", project_id)
            .eq("sprint_number", sprint_numero)
            .eq("tipo_documentacao", "planning")
            .order("created_at", desc=True)
            .limit(1)
            .execute()
        )
        if resp.data:
            campos_planning = resp.data[0].get("extracted_content", {}).get("campos_planning", {})
    ```

    Na chamada de `_replace_placeholders()` que atualmente passa `"SQUAD": "[A definir]"` e `"PERIODO": "[A definir]"`, substituir por:

    ```python
    _replace_placeholders(docs, doc_id, {
        "PROJETO": projeto_nome,
        "CLIENTE": cliente,
        "TIPO_DOC": doc_type_label,
        "SPRINT": sprint_label,
        "SPRINT_NUM": str(sprint_numero) if sprint_numero else "—",
        "DATA": data_fmt,
        "SQUAD": campos_planning.get("squad") or "—",
        "PERIODO": (
            f"{campos_planning.get('periodo_inicio', '')} a {campos_planning.get('periodo_fim', '')}"
            if campos_planning.get("periodo_inicio") or campos_planning.get("periodo_fim")
            else "—"
        ),
        "HORAS_REAIS": str(campos_planning.get("horas_disponiveis") or "—"),
        "HORAS_ESTIMADAS": str(campos_planning.get("horas_estimadas") or "—"),
        "DEPENDENCIAS_CLIENTE": campos_planning.get("dependencias_cliente") or "—",
        "CARRY_OVER": campos_planning.get("carry_over") or "—",
    })
    ```

    Se sprint_numero é None ou doc_type não é "planning", os valores de campos_planning ficam `{}` e os fallbacks `"—"` são usados.
  </action>
