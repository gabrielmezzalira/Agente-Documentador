<objective>
Add a `validar_tipo` node to the extraction graph — the first node executed, before `detectar_tipo` and `preprocessar_arquivo`. The node calls Gemini with a short classification prompt, determines whether the uploaded content matches the expected document type, and either halts the graph (returning an error state) or passes control to the existing `detectar_tipo` node.

Purpose: Prevent semantically mismatched content from being saved to Supabase — a review document submitted as a planning, or an ML lecture submitted as any project document, is caught before any extraction runs.

Output: `extraction_graph.py` with seven new `ExtractionState` fields, a `validar_tipo` async node function, `_VALIDATION_SYSTEM_PROMPT`, and an updated graph topology (START → validar_tipo → detectar_tipo).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uploaded file → validar_tipo node | File bytes from untrusted user input are decoded and sent to Gemini for classification |
| Gemini response → _roteador_validacao | Gemini classification output determines whether extraction proceeds |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | validar_tipo — Gemini response parsing | medium | mitigate | json.loads parse errors default to nao_bloquear=True (safe fallback); no user-controlled value is exec'd |
| T-05-02 | Denial of Service | validar_tipo — large binary files in preview | low | mitigate | Preview capped at 3000 bytes; binary decode uses errors='replace' — no unbounded processing |
| T-05-03 | Spoofing | force=True bypass | low | accept | force is a deliberate override by the project manager (authenticated via API key); override is logged in extracted_content as _meta_force_override |
| T-05-04 | Information Disclosure | Gemini explicacao field in error message | low | accept | Gemini explanation is one sentence about document category — no private data returned |
</threat_model>
